# Note偏差値診断ビルダー

note運用実績を入力すると「note偏差値」「戦闘力」「大学ランク」を採点し、
ChatGPT用の診断カード画像プロンプトを生成するシングルファイルHTMLツール。
成長記録（履歴・推移グラフ・前回比）、昇格演出、次の一手ナビ、実績バッジ、
結果カードPNG、成長プロンプト（ビフォーアフター／昇格辞令・留年通知）を搭載。

- **原作プロンプト**: 営業fafa｜note業界No.1営業マン (note.com/kohana1112)
- **ツール化**: KITAcore

## バージョン

現行 **v2.2.0** (build 2026-07-22) / データ形式 schema 1
バージョン運用は セマンティックバージョニング（メジャー.マイナー.パッチ）。
最新の更新履歴はツール内「使い方 → 更新履歴」を参照。

## 公開（Cloudflare Pages）

- 配信: Cloudflare Pages（このリポジトリを接続、pushで自動デプロイ）
- エントリ: `index.html`（ルート）
- ビルド不要（フレームワークなしの静的サイト）

## ローカルで確認

```bash
# このフォルダで簡易サーバを起動して http://localhost:8000 を開く
python3 -m http.server 8000
```

## ファイル

- `index.html` … 本体（公開されるファイル）
- `note-hensachi-builder.html` … 同一内容の別名コピー（参照用）
- `404.html` … 存在しないパス用
- `.nojekyll` … （GitHub Pages併用時に）Jekyll処理を無効化

## データについて

診断の記録はブラウザの localStorage に保存され、サーバーには送信されません。
端末・ブラウザをまたぐと共有されないため、ツール内の「バックアップ書き出し／読み込み」で移行できます。
