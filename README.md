# Note偏差値診断ビルダー V3 — IMP×PV Edition

note運用実績を入力すると「note偏差値」「戦闘力」「大学ランク」を採点し、
ChatGPT用の診断カード画像プロンプトを生成するシングルファイルHTMLツール。
成長記録（履歴・推移グラフ・前回比）、昇格演出、次の一手ナビ、実績バッジ、
結果カードPNG、成長プロンプト（ビフォーアフター／昇格辞令・留年通知）を搭載。

**V3（v3.0.0）** で note ダッシュボード刷新（ビュー → インプレッション＋PV）に対応。

- 入力：月間ビュー → **月間インプレッション数 ＋ 月間PV数** の2項目
- 新指標：**開封効率**（PV ÷ インプレッション × 100）を自動計算し、最大6点で採点
- スキ率の分母を ビュー → **PV** に変更（閾値も引き上げ）
- エンゲージメント30点の内訳：スキ8 ／ スキ率8 ／ コメント8 ／ 開封効率6
- **露出タイプ**：インプレッション × 開封効率の四象限（主力型／潜在力型／露出先行型／育成型）でアカウントの現在地と次の一手を表示（スコアには加算しない）
- 基本スコア100点・偏差値スケール（30〜80）・大学ランク表は据え置き
- 閾値は `index.html` 内の `TH` オブジェクトに集約（すべて暫定値。実データの分位点で再校正する前提）

- **原作プロンプト**: 営業fafa｜note業界No.1営業マン (note.com/kohana1112)
- **V3 再設計・制作**: KITAcore（v1 HTMLツール化 → v2 成長記録 → V3/v3 IMP×PV対応で採点を再設計）

## バージョン

現行 **v3.0.0** (build 2026-10-23) / データ形式 schema 2（schema 1 の記録はそのまま読込可。旧記録には開封効率・露出タイプが無いため「判定なし」になる）
バージョン運用は セマンティックバージョニング（メジャー.マイナー.パッチ）。
最新の更新履歴はツール内「使い方 → 更新履歴」を参照。

- エントリ: `index.html`（ルート）

## データについて

診断の記録はブラウザの localStorage に保存され、サーバーには送信されません。
端末・ブラウザをまたぐと共有されないため、ツール内の「バックアップ書き出し／読み込み」で移行できます。

本ツールはエンタメ診断です。偏差値・大学ランクは実際の能力や社会的評価を示すものではありません。
